Get the CSV from IBKR

  1. Flex Query (preferred). Log in to Client Portal → Performance & Reports → Flex Queries → open (or create) the Activity Flex Query named Monthly_Realised_PnL.
  2. Include these sections: Trades, Cash, InterestAccruals, CashReport and Realized Base (the Realized/Unrealized P&L section with its currency set to Base).
  3. Set Format: CSV and Period: Last Month, then Run / Download the file and save it in this dashboard's data/ folder.
  4. Fallback — Activity Statement. Reports → Statements → Activity, pick the monthly period and download the CSV; the parser understands both layouts.

Freshness. IBKR can take up to 5 business days after month-end to finalise the previous month, and Flex Queries cannot include the current trading day — re-run once the month has closed.

Privacy. The file is parsed in this browser only: nothing is uploaded and nothing leaves your machine.
