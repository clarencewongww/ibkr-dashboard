Get the CSV from IBKR

  1. Flex Query (preferred). Log in to Client Portal → Performance & Reports → Flex Queries → + and create an Activity Flex Query named Monthly_Realised_PnL.
  2. Add these sections and fields (Level of Detail: Executions for Trades):
    • Trades — 11 fields: FXRateToBase, AssetClass, Symbol, TradeDate, Quantity, TradePrice, Proceeds, IBCommission, Notes/Codes, CostBasis, FifoPnlRealized.
    • Cash Transactions — 4 fields: Description, Date/Time, Amount, Type.
    • Interest Accruals — 7 fields: CurrencyPrimary, FromDate, ToDate, StartingAccrualBalance, InterestAccrued, AccrualReversal, EndingAccrualBalance.
    • Cash Report — select all columns (detection only).
    • Realized/Unrealized P&L — currency Base, 8 fields: AssetClass, Symbol, RealizedShortTermProfit, RealizedShortTermLoss, RealizedLongTermProfit, RealizedLongTermLoss, TotalRealizedPnl, TotalUnrealizedPnl (detection only).
  3. General Configuration. Format CSV, Date Format yyyy-MM-dd, and switch Include Column Headers and Section Code ON.
  4. Save & run. Save the query, set Period: Year to Date, then Run / Download the file and save it in this dashboard's data/ folder.
  5. Fallback & freshness. No Flex Query? Reports → Statements → Activity, pick the monthly period and download the CSV; the parser understands both layouts. IBKR can take up to 5 business days after month-end to finalise the previous month, and a Flex Query cannot include the current trading day — re-run once the month has closed. The file is parsed in this browser only: nothing is uploaded and nothing leaves your machine.

Extra columns are fine. The parser keys off the sections above and ignores anything else, so a wider export still loads. The same walkthrough lives in README §1.
